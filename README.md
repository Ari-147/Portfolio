# Muhammad Ali — MERN Stack Developer Portfolio

A modern, interactive portfolio website showcasing full-stack development projects and expertise in MERN stack technologies and AI integration.

> **Status**: Available for work | **Location**: Sahiwal, Punjab, Pakistan | **University**: COMSATS, 2027

---

## 🎯 About

This is a professional portfolio website built with vanilla HTML, CSS, and JavaScript. It features a modern, dark aesthetic with smooth animations, particle effects, and interactive elements that showcase technical skills and projects.

---

## ✨ Key Features

- **Custom Cursor Animation** — Smooth, interactive cursor with trailing ring effect
- **Particle Canvas Background** — Animated floating particles for visual depth
- **Smooth Page Loader** — Engaging "MA" branded loader with progress bar
- **Responsive Navigation** — Sticky nav with numbered sections and mobile menu
- **Hero Section** — Eye-catching animated title with status indicators
- **Smooth Scroll Behavior** — Seamless navigation between sections
- **Noise Overlay Effect** — Subtle texture for enhanced visual polish
- **Mobile Responsive** — Fully optimized for all device sizes
- **Performance Optimized** — Lightweight vanilla JavaScript (no frameworks)

---

## 🛠️ Tech Stack

- **Frontend**: HTML5, CSS3, Vanilla JavaScript
- **Typography**: Google Fonts (Inter, Space Mono)
- **Animations**: CSS Animations + Canvas API
- **Canvas Graphics**: Particle system for background effects
- **Responsive Design**: Mobile-first approach with media queries

## 🚀 Getting Started

### Prerequisites
- No build process required
- Works in any modern web browser
- Internet connection for Google Fonts

### Installation

1. Clone or download this repository
```bash
git clone <repository-url>
cd portfolio
```

2. Open in your browser
```bash
# Simply open index.html in your preferred browser
# Or use Live Server for local development
```

### Development

For local development with live reload:
- Use VS Code Live Server extension, or
- Run a simple HTTP server: `python -m http.server 8000`

## 🎨 Customization

### Colors
Edit CSS variables in `style.css`:
```css
:root {
    --bg: #070707;           /* Background */
    --green: #3ddc84;        /* Accent color */
    /* ... more colors ... */
}
```

### Content
Update text, images, and links directly in `index.html`

### Effects
Adjust particle speed, cursor effects, and animations in `script.js`
